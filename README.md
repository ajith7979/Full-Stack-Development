# FlyEasy Airlines Landing Page

A responsive landing page for FlyEasy Airlines flash sale campaign.

## Assignment Details

This project is created for Full Stack Development course assignment.

**Topic:** Responsive Landing Page using HTML & CSS

## About

This is a landing page for a budget airline's flash sale offering 50% off on Asia flights. The page is fully responsive and works on mobile, tablet, and desktop devices.

## Files Included

- `index.html` - Main HTML file
- `style.css` - CSS stylesheet

## Sections

1. **Header** - Logo and navigation menu
2. **Hero Section** - Main banner with flash sale offer
3. **Features** - Three feature cards (Non-stop routes, Free meals, Flexible booking)
4. **Pricing** - Two pricing plans (Economy and Premium)
5. **Footer** - Contact information and social links

## Features

- Responsive design (works on mobile and desktop)
- Sticky header
- Hover effects on cards and buttons
- CSS-only hamburger menu for mobile
- Smooth animations

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Playfair Display, Space Grotesk)
