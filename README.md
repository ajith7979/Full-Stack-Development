FlyEasy Airlines – Responsive Landing Page

A modern and responsive landing page designed for FlyEasy Airlines to promote a 50% flash sale on Asia flights.

Assignment Details

Course: Full Stack Development

Assignment Type: Frontend UI Design

Topic: Responsive Landing Page using HTML & CSS

About the Project

This project is a responsive airline landing page created to showcase a limited-time flash sale offering 50% off on flights to popular Asian destinations such as Bangkok, Singapore, Tokyo, and Bali.

The design focuses on:

Clean airline-style UI

Professional layout

Smooth user experience across devices

The page works seamlessly on desktop, tablet, and mobile screens without using JavaScript.

Project Structure
├── index.html   → Main HTML file
├── styles.css   → External CSS stylesheet
└── README.md    → Project documentation

Sections Included

Header – Logo and navigation bar with sticky behavior

Hero Section – Flash sale banner with call-to-action buttons

Features Section – Airline services and benefits

Destinations Section – Popular Asian travel destinations

Pricing Section – Economy and Premium fare plans

Footer – Contact details, certifications, and quick links

Key Features

Fully responsive design (mobile, tablet, desktop)

Sticky navigation header

CSS-only hamburger menu for mobile view

Hover effects and smooth transitions

Card-based layout for features, destinations, and pricing

Professional airline-themed UI
